# Miguel's Baja Grill Restaurante

Landing page para **Miguel's Baja Grill**, un restaurante de cocina estilo Baja California ubicado en Moab, Utah.

El sitio fue desarrollado como una página web informativa y responsive, enfocada en presentar de manera clara el menú, información del restaurante, ubicación, horarios y diferentes formas de contacto.

## 🌮 Características

- Landing page responsive para dispositivos móviles, tablets y escritorio.
- Sección principal con información destacada del restaurante.
- Información sobre Miguel's Baja Grill.
- Menú organizado por categorías.
- Fotografías de diferentes platillos.
- Información de precios y descripciones.
- Sección especial de margaritas.
- Información de ubicación y horarios.
- Mapa de Google Maps integrado.
- Botones para llamar directamente al restaurante.
- Enlaces a Google Maps para obtener indicaciones.
- Enlaces a redes sociales.
- Barra de acciones para dispositivos móviles.
- Navegación responsive con menú móvil.

## 🛠️ Tecnologías utilizadas

- **JavaScript**
- **React**
- **HTML5**
- **CSS3**
- **Vite**
- **React Icons**

## 📱 Responsive Design

El sitio está diseñado para adaptarse a diferentes tamaños de pantalla, ofreciendo una experiencia de navegación cómoda tanto en dispositivos móviles como en computadoras de escritorio.
